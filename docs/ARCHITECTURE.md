# RentGuard AI 아키텍처

## 설계 원칙

1. **판단과 설명을 분리한다.** Rule/ML 엔진이 위험 신호와 점수를 만들고, LLM은 근거를 바꾸지 않은 채 쉬운 문장으로 설명한다.
2. **원문과 추출값을 함께 보존한다.** 각 필드는 문서, 페이지, 원문 좌표를 추적할 수 있도록 확장한다.
3. **모르는 것은 모른다고 표시한다.** 확인 불가 항목은 안전으로 간주하지 않고 `needs_review`로 반환한다.
4. **법률 판단을 단정하지 않는다.** 결과는 계약 의사결정 보조 정보이며 공식 서류 재확인과 전문가 상담을 안내한다.

## 데이터 흐름

```text
주소·계약조건·문서
        │
        ▼
문서 분류 → OCR → 필드 정규화
        │
        ├──────────────┐
        ▼              ▼
국토부 실거래가     건축물대장
        └──────┬───────┘
               ▼
       교차검증 + Rule Engine
               │
          ML 이상치 모델
               │
               ▼
       점수·위험 신호·행동
               │
               ▼
       공식자료 RAG + LLM 설명
```
