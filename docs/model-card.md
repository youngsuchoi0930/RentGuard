# RentGuard 모델 카드

README에는 핵심 성과를, 이 문서에는 학습·보정·평가의 세부 조건을 기록합니다.
기존 학습 리포트의 집계값은 [model-reports.json](evaluation/model-reports.json),
단순 기준선의 사후 재평가는 [deposit-baseline.json](evaluation/deposit-baseline.json)에서 확인할 수 있습니다.

## 1. API에 연결된 보증금 모델

| 항목 | 설정 |
|---|---|
| 산출물 | `models/deposit-quantile-v2.joblib`, 스키마 `deposit-quantile-model-2.0` |
| 라이브러리 | scikit-learn 1.9.0 |
| 전처리 | 결측치 중앙값 대체, 결측 indicator 추가 |
| 모델 | `HistGradientBoostingRegressor(loss="quantile")` |
| 구성 | 전세·월세별 p50(0.50), p95(0.95), 총 4개 회귀 파이프라인 |
| 파라미터 | learning rate 0.06, 최대 250회, leaf 31개, leaf 최소 표본 30개, L2 0.2 |
| 조기 종료 | validation fraction 0.1, 20회 연속 개선 없으면 종료 |
| 목표값 | `log1p(보증금(백만원) / 전용면적㎡)`; 추론 후 원 단위 전체 보증금으로 변환 |
| p50 입력 | 면적·층/지하·연식·월세·시점·계약유형·갱신권·직전 계약·유사 계약 통계 등 23개 |
| p95 입력 | 면적·층·연식·월세·시점·갱신 여부·직전 보증금·유사 계약 통계 등 12개 |
| 제외 정보 | 현재 제안 보증금, 이름, 상세주소, PDF/OCR 원문, 등기 권리정보 |
| 용도 | 서울 연립·다세대 전월세의 보증금 중앙값·상위 경계 추정 |
| 로드 검증 | manifest의 파일명·크기·SHA-256과 모델 스키마 검사 |

학습 시각은 `2026-09-12T05:20:29.380731+00:00`, 모델 크기는 3,872,049바이트입니다.
SHA-256은 `1e62a7c48bd59790b462cea3ca7448a09f57c3e77d144191203552b92b788531`입니다.
[Manifest](../models/deposit-quantile-v2.manifest.json) · [학습 구현](../scripts/train_deposit_quantile.py) · [특성 구현](../apps/api/app/services/deposit_quantile_features.py)

p95 초과는 시장 범위 밖의 계약 조건을 확인하라는 신호입니다. 규칙 점수에는 0점으로 합산하며,
실제 사기·보증사고·법적 안전 여부를 학습한 모델이 아닙니다.

## 2. 데이터와 분할

국토교통부 서울 연립·다세대 전월세 신고자료를 사용합니다. 원자료의 SHA-256은 공개 집계 리포트에 기록되어 있습니다.
현재 제안 보증금은 목표값에만 사용하고 예측 입력에는 넣지 않습니다.

| 구분 | 건수·기간 |
|---|---:|
| 공공 거래 원자료 | 271,842건 |
| 적격 거래 / 부적격 제외 | 271,142건 / 700건 |
| 초기 학습 후보 | 217,201건, 보정·홀드아웃 이전 |
| 초기 학습 표본 | 119,759건, 극단값 제외 후 |
| 보정 표본 | 23,161건, 2026-04~05 |
| 최종 학습 표본 | 119,951건, 2026-05까지 |
| 최종 학습 전세 / 월세 | 47,215건 / 72,736건 |
| 홀드아웃 | 30,780건, 2026-06~08 |
| 합성 이상 조건 | 19,985건, 적격성 조건 통과분 |

적격 조건은 보증금·㎡당 보증금이 양수이고 전용면적이 5~300㎡인 거래입니다.
초기 학습 자료의 계약형태별 목표값 0.1~99.9백분위로 극단값 범위를 정하고,
같은 범위를 최종 학습 표본에도 적용합니다. 기본 표본 상한은 120,000건, seed는 20260910입니다.
개인 등기부·건축물대장·계약서는 추출·대조 회귀 확인에만 사용하며 이 ML 학습·보정·평가에 포함하지 않습니다.

## 3. 보정과 최종 재학습

1. 2026-04 이전 자료로 임시 모델과 유사 거래 통계 기준을 구성합니다.
2. 2026-04~05 잔차로 전세·월세별 p50 중앙 잔차와 p95 상위 잔차 보정값을 고정합니다.
3. 초기 학습 표본과 보정 표본을 합쳐 최종 표본을 다시 선택·학습하고 유사 거래 통계도 다시 구성합니다.
4. 최종 모델에 고정된 보정값을 적용하여 2026-06~08을 평가합니다. 홀드아웃 목표값은 학습·보정 특성 구성에 넣지 않습니다.

보정 표본은 최종 학습에도 사용합니다. 이 절차는 **독립 보정셋과 고정 모델을 유지하는 split-conformal 보장과 동일하지 않습니다**.
보고된 95% 포함률은 해당 과거 평가 구간의 관측치이며 시간 변화·조건별 포함률을 보장하지 않습니다.
또한 같은 홀드아웃으로 v1·v2를 비교했으므로 후속 모델 선택에는 새 평가 기간이나 시간 순차 검증이 필요합니다.
초기 학습의 유사 거래 통계와 조기 종료는 거래별 완전한 시간 순차 검증으로 구성한 것은 아닙니다.

| 보정 구간 진단 | 표본 | 임시 모델 보정 전 p95 포함률 | 보정 후 |
|---|---:|---:|---:|
| 전세 | 8,986 | 91.8985% | 95.0256% |
| 월세 | 14,175 | 92.4938% | 95.0194% |

위 표는 **보정 표본 자체의 진단값**이며 최종 모델의 홀드아웃 성능과 구분합니다.

## 4. 전체 홀드아웃 성능

MAE는 거래별 전체 보증금 절대오차의 평균, 중앙 절대비율오차는 `median(abs(actual-p50)/actual)`입니다.
p95 포함률은 `mean(actual <= p95)`, 초과 플래그 비율은 그 여집합입니다.

| 지표 | v1 | v2 |
|---|---:|---:|
| p50 MAE | 2,996.61만원 | 2,946.94만원 |
| p50 중앙 절대비율오차 | 14.3594% | 13.9317% |
| p95 포함률 | 92.2807% | 95.0325% |
| p95 초과 플래그 비율 | 7.7193% | 4.9675% |
| 합성 이상 조건 전체 탐지율 | 78.8291% | 75.9019% |
| 합성 보증금 급등 탐지율 | 84.9258% | 84.0258% |
| 합성 갱신 보증금 급등 탐지율 | 92.7993% | 91.1341% |
| 합성 월세 급등 탐지율 | 58.7192% | 52.4955% |
| 합성 보증금/p95 중앙 비율 | 2.010699배 | 1.895515배 |

v2는 v1 대비 MAE를 약 1.66% 줄였습니다. 합성 전체 탐지율은 약 2.93%p 감소했습니다.
전체 포함률이 목표에 가까워진 점과 중앙값 오차를 우선했고, 탐지 민감도 하락을 함께 기록합니다.
개선의 통계적 유의성·seed별 분산·지역별 조건부 포함률은 아직 측정하지 않았습니다.

## 5. 단순 기준선 사후 비교

기준선은 최종 v2 artifact의 `peer_reference`에서 ㎡당 보증금 중앙값을 찾아 대상 면적을 곱합니다.
그룹은 `구·법정동·10㎡ 면적대·전세/월세` → `구·면적대·전세/월세` → `구·전세/월세` → `전세/월세` 순서로 대체합니다.
최소 그룹 표본은 각각 20·40·80·1건입니다. 홀드아웃의 보증금은 통계 구성에 사용하지 않습니다.

| 평가 구간 | 표본 | 기준선 MAE | v2 MAE | 기준선 중앙 비율오차 | v2 중앙 비율오차 | v2 p95 포함률 |
|---|---:|---:|---:|---:|---:|---:|
| 전체 | 30,780 | 6,582.84만원 | 2,946.94만원 | 46.38% | 13.93% | 95.0325% |
| 전세 | 11,507 | 6,091.68만원 | 2,814.94만원 | 18.42% | 6.69% | 94.9335% |
| 월세 | 19,273 | 6,876.09만원 | 3,025.74만원 | 70.37% | 24.71% | 95.0916% |

전체 MAE 감소율은 55.23%입니다. 이 기준선은 월세액·층·연식을 직접 반영하지 않는 단순 비교이며,
같은 특성을 사용하는 대체 회귀 모델과의 비교 실험은 아닙니다. 2026-10-27 기존 홀드아웃을 재사용한 사후 평가입니다.
[재평가 구현](../scripts/evaluate_deposit_baseline.py)은 데이터 SHA-256, 모델 manifest, 평가 표본 수와 기존 v2 MAE 일치를 확인하고 집계값만 출력합니다.

## 7. 적용 한계

- 실제 사기·보증사고 라벨이 없어 해당 사고의 정확도·정밀도·재현율·F1을 보고하지 않습니다.
- 합성 탐지율은 정한 변형 시나리오의 반응이며 실제 사고 탐지 성능이 아닙니다.
- 월세의 비율오차가 전세보다 큽니다. 입력 계약정보 누락·시장 변화·새 지역/주택유형에 대한 일반화 평가가 더 필요합니다.
- 면적·모델·유사 거래 기준이 없거나 학습 적용 범위 밖이면 `unavailable` 또는 `out_of_scope`로 반환합니다.
- 원자료는 Git에 포함하지 않습니다. 공개 집계로 수치와 기준을 확인할 수 있지만 전체 재현에는 같은 SHA-256의 원자료가 필요합니다. API 재수집 데이터는 갱신·취소 신고로 달라질 수 있습니다.
