# RentGuard 위험 정책 v2.1.0

> 시행일: 2026-09-28  
> 기계 판독 기준: `docs/risk-policy-v2.json`  
> 코드 기준: `apps/api/app/risk_engine.py`, `apps/api/app/services/analysis_service.py`

## 1. 목적과 한계

이 정책은 계약의 법적 안전 여부나 사기 여부를 판정하지 않는다. 점수는 사용자가 먼저 확인해야 할 항목의 **제품 내부 우선순위**이며, 보증 가입 승인·대출 승인·법률 자문을 대신하지 않는다.

- 공식기관이 RentGuard의 점수나 등급을 승인한 것이 아니다.
- 비율 임계값과 가점은 공식자료의 확인 항목을 참고해 제품 내부에서 정한 휴리스틱이다.
- `채권최고액`은 실제 대출 잔액과 다를 수 있다.
- 순위번호만으로 임차보증금의 법적 우선순위를 확정하지 않는다.
- 공공데이터나 문서 값이 없으면 `안전`으로 간주하지 않고 `확인 필요`로 남긴다.

## 2. 점수와 등급

위험점수는 활성 신호의 점수를 합산하고 `100점`에서 상한 처리한다. 말소된 등기 권리는 합산하지 않으며, 같은 권리 유형이 여러 건이어도 해당 유형의 신호는 한 번만 가점한다.

| 조건 | 등급 | 처리 |
|---|---|---|
| 예상 주택가액 미확인 | 주의 | 점수와 별도로 시세 확인 필요 표시 |
| 점수 65점 이상 | 높음 | 우선 확인이 필요한 계약으로 표시 |
| 점수 35~64점 | 주의 | 추가 확인 필요 표시 |
| 35점 미만이지만 `danger` 신호 존재 | 주의 | 낮음 등급 방지 |
| 그 외 | 낮음 | 현재 확인된 신호가 낮다는 뜻이며 안전 보장은 아님 |

활성 압류·가압류·신탁·전세권·임차권·경매 신호가 있으면 등기 권리 확인을 우선하도록 최소 `주의` 등급을 적용한다.

## 3. 금액·시세 신호

| 신호 | 조건 | 단계 | 점수 | 행동 |
|---|---|---:|---:|---|
| 선순위 부담 | `(근저당 채권최고액 + 보증금) / 예상 주택가액 >= 100%` | danger | 35 | 잔금 전 근저당 말소 특약 확인 |
| 선순위 부담 | 같은 비율 `80% 이상 100% 미만` | warning | 24 | 최신 시세와 대출 잔액 확인 |
| 근저당 비율 | `근저당 / 예상 주택가액 >= 50%` | danger | 20 | 잔금 전 근저당 말소 특약 확인 |
| 근저당 비율 | 같은 비율 `30% 이상 50% 미만` | warning | 12 | 최신 등기와 대출 잔액 확인 |
| 근저당 존재 | 시세 미확인이고 채권최고액이 존재 | warning | 12 | 잔금 전 근저당 말소 특약 확인 |
| 보증금 비율 | `보증금 / 예상 주택가액 >= 80%` | danger | 18 | 시세와 선순위 권리 함께 확인 |
| 보증금 비율 | 같은 비율 `65% 이상 80% 미만` | warning | 8 | 가격 하락 여유 확인 |
| 거래 표본 부족 | 비교 거래 `5건 미만` | notice | 6 | 자동 추정 범위가 넓을 수 있음을 표시 |
| 가격 변동성 | ㎡당 가격 변동계수 `7% 이상` | notice | 4 | 복수 시세 자료 비교 안내 |
| 시세 미확인 | 예상 주택가액 없음 | notice | 0 | 비율을 계산하지 않고 확인 필요 표시 |
| 보증금 ML 상위 경계 | 입력 보증금이 예측 상위 95% 경계 초과 | warning | 0 | 이상 신호만 제공하고 규칙 점수에는 미합산 |

HUG가 사용하는 부채비율 역시 선순위채권과 전세보증금, 주택가액의 관계를 보지만, RentGuard의 `35점·24점` 등 가점 자체는 HUG 심사 점수가 아니다.

## 4. 문서·권리 신호

| 신호 | 조건 | 단계 | 점수 | 핵심 행동 |
|---|---|---:|---:|---|
| 소유자 불일치 | 등기 소유자와 계약서 임대인이 다름 | danger | 25 | 본인 또는 적법한 위임 원본 확인 |
| 위반건축물 | 건축물대장 값이 `true` | danger | 22 | 관할 구청·보증기관 확인 |
| 압류 | 활성 압류 존재 | danger | 25 | 원인과 말소 여부 확인 |
| 가압류 | 활성 가압류 존재 | danger | 22 | 청구금액과 말소 조건 확인 |
| 신탁 | 활성 신탁 존재 | danger | 30 | 신탁원부와 수탁자 동의 확인 |
| 전세권 | 활성 전세권 존재 | warning | 15 | 순위와 말소 조건 확인 |
| 임차권등기 | 활성 임차권 존재 | warning | 18 | 원인과 말소 여부 확인 |
| 경매개시결정 | 활성 경매개시결정 존재 | danger | 35 | 사건 진행 상태와 전문가 검토 |

## 5. 행동 지침 조립

결과 화면에는 최대 세 가지 행동을 표시한다.

1. 동일 문구를 중복 제거한다.
2. 최신 등기부 재확인 행동이 없으면 앞에 추가한다.
3. 위험별 구체 행동을 유지한다.
4. 공간이 남으면 HUG 등 보증기관 직접 확인을 추가한다.
5. 활성 등기 권리가 있으면 해당 권리의 구체 행동을 일반 행동보다 우선한다.

행동이 세 개를 넘으면 앞선 우선순위의 세 개만 표시한다. 따라서 여러 활성 권리가 동시에 발견되면 보증기관 안내보다 개별 권리 조치가 먼저 표시될 수 있다.

## 6. 공식 참고자료

- [HUG 전세보증금반환보증 상품개요](https://www.khug.or.kr/hug/web/ig/dr/igdr000001.jsp): 주택가격·선순위채권·전세보증금 관계와 보증 조건 확인
- [국토교통부 안심 전세계약 체크리스트](https://www.molit.go.kr/USR/NEWS/m_71/dtl.jsp?id=95091216&lcmspage=1): 계약 전후 등기·당사자·주택 상태 확인
- [정부24 건축물대장 발급·열람](https://www.gov.kr/mw/AA020InfoCappView.do?CappBizCD=15000000098&tp_seq=03): 집합건축물대장 표제부·전유부 등 최신 원문 확인

공식자료는 **확인할 항목과 행동의 근거**이며 RentGuard의 개별 가점을 정하는 법적 근거가 아니다. 보증 조건은 변경될 수 있으므로 실제 계약 시 공식 사이트에서 다시 확인한다.

## 7. 변경 절차

정책을 변경할 때는 다음을 한 커밋에서 함께 수정한다.

1. `risk-policy-v2.json`의 조건·점수·행동과 `policy_version`
2. 위험 엔진 또는 분석 조립 코드
3. 경계값·점수·등급·행동 중복 회귀 테스트
4. 이 문서의 표와 변경 이력
5. 필요하면 공식자료 확인일과 링크

버전은 점수·임계값·등급처럼 결과가 달라지는 변경은 minor 이상, 문구만 명확히 하는 변경은 patch를 올린다.
