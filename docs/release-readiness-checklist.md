```powershell
cd apps/api
.venv\Scripts\python -m pytest -q
.venv\Scripts\python -m pip_audit -r requirements-ci.txt

cd ..\web
pnpm lint

pnpm exec playwright install chromium
pnpm test:e2e

cd ..\..
pnpm audit:web
docker compose config -q
git diff --check
```

## 남아 있는 비차단 한계

- PaddleOCR 전용 테스트는 기본 테스트에서 제외되므로 필요할 때 `RUN_OCR_TESTS=1`로 별도 실행한다.
- 건축HUB가 위반건축물 여부를 주지 않는 경우 서비스가 임의 판단하지 않고 `확인 불가`로 표시한다.
- HUG 보증 가입 가능 여부는 자동 확정하지 않고 보증기관 직접 확인을 안내한다.
- 비공개 원본과 기준선은 Git 제외 경로에서 관리하며 `--cases-dir <비공개_문서_경로>`로 전체 재검증한다.
- 실제 문서 레이아웃 수가 적으므로 새 레이아웃 정확도는 추가 익명 사례가 생길 때 확장한다.

## 마무리 판정

요청한 로컬 마무리 범위의 차단 오류는 발견되지 않았다. 실제 배포는 수행하지 않았으며,
배포를 결정할 때에는 운영 HTTPS, 비밀키 주입, 로그 마스킹, 백업·삭제 정책, 오류 관측을
별도의 운영 체크리스트로 다시 검증해야 한다.
